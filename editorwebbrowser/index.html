What it is

Editor Web Browser puts a web browser in the Unreal Editor. The browser is a normal editor tab. You can dock it, float it and arrange it like all other tabs.

A maximum of four browsers can be open at the same time. The browsers keep your session. If you sign in to a site today, you are still signed in tomorrow, after you close the editor and open it again.

How to install

  1. Install the plugin into your engine version from the store.
  2. Open your project. Go to Edit -> Plugins and select the Other category. Then select the Enabled check box for Editor Web Browser.
  3. Restart the editor.

How to use

Opening a browser

To open a browser, select Tools -> Web Browser. There are four browsers: Web Browser 1 to Web Browser 4.

Each browser is a normal editor tab. You can dock it next to the viewport, drag it to a second monitor, or let it float. The editor layout keeps the tab where you put it.

When only one browser is open, the name of the tab is Web Browser. The numbers appear only when a second browser is open. Thus you see the numbers only when you need them.

All four browsers use one session. Thus, if you sign in to a site in one browser, you are also signed in to it in the other browsers.

The toolbar

The toolbar has these controls, from the left:

  • back and forward go through the pages that you visited.
  • home goes to your homepage.
  • reload changes to a stop button while a page loads.
  • The address bar. To go to a page, type its URL and press Enter.

The star on the right side of the address bar adds the current page to your favourites. If the page is already in your favourites, the star removes it.

Favourites and history

The menu button at the far right of the toolbar opens a menu with the other items:

  • Favorite shows the pages that you added with the star. To go to a page, select it.
  • History shows the pages that you visited most recently. To empty the list, select Clear History at the bottom.
  • Open in System Browser opens the current page in your usual desktop browser.
  • Set As Homepage makes the current page your homepage. The home button then goes to this page.
  • Capture Editor Shortcuts sets which one gets your keystrokes: the page or the editor. See Capture Editor Shortcuts.

The plugin saves your favourites and your history each time that they change. They are there the next time that you open the editor.

Staying signed in

The browser keeps its cookies when you close the editor. Sign in to a site one time, and you stay signed in when the editor restarts. This is the difference between this plugin and a separate browser window next to the editor.

For example, you can sign in to:

  • A wiki.
  • A task tracker.
  • A documentation site.
  • Your own web tools.

The plugin keeps the session outside your project. Thus the source control of your project cannot contain the session.

Capture Editor Shortcuts

When you type in a web page, a keystroke such as Ctrl+S can have two meanings. The page can use it, and the editor can also use it. Capture Editor Shortcuts, in the toolbar menu, sets which one gets the keystroke.

SettingResult
On (default)The page receives the keystroke. Editor shortcuts do not operate while you use the browser.
OffThe editor shortcuts continue to operate. The page receives only the keys that the editor does not use.

If you use web applications in the browser, keep the setting On. If you usually only read pages and you want your editor shortcuts available, set it to Off.
