Introduction

This plugin is for asset creators who often examine the results of their work in the game engine. With this plugin, the reimport occurs automatically, and this saves you time. You can also use the editor window as an asset preview. You do not need to leave the program that you use to make the asset. Export the asset to the same location from which you imported it before. The plugin does all the other steps.

Enabling Plugin

To enable the plugin, do these steps:

  1. Go to Edit -> Plugins.
  2. Select the Editor category.
  3. Select the Enabled check box for Smart Auto Reimport.

How to use it

To monitor assets, do these steps:

  1. In the Content Browser, select the assets that you want to monitor.
  2. Right-click one of the selected assets, then select "Auto Reimport" in the context menu.
  3. Select the "Auto Reimport" check box.

The Auto Reimport status of an asset shows in the lower-left corner of the asset icon. It also shows in the context menu.

After this, each time the source file of an asset changes, the editor reimports the asset automatically.

FAQ

Which types of assets does the plugin support?

All types of assets that you can import into the editor work with the plugin. The plugin is a layer on the reimport function that the editor already has. Thus it works with all compatible asset types.

Can I use this plugin in Standalone Game mode?

No. The reimport function works only in the editor.

Does the plugin work in Play-In-Editor (PIE) mode?

Yes, but not for all types of assets. Textures and static meshes refresh. Sounds, for example, do not refresh. The behavior of the plugin depends on the implementation of each asset type.

Why does the plugin not keep the list of monitored assets after the editor restarts?

This prevents some unusual use cases. There is no decision yet about how the plugin must handle them.

Why do I not see the "Auto Reimport" option?

  • Make sure that the plugin is enabled.
  • Make sure that the editor can reimport the selected assets.
