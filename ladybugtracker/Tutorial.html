Getting Started

LadyBug Tracker

___________________________________

Tutorial

Author: Tomasz Klin

Version: 1.0.0

Last Update: 04.11.2018

This tutorial is an overview. It shows you most of the basic functions of the plugin. Before you start it, I recommend that you read the documentation carefully.

Getting Started

  1. Install the LadyBug Tracker plugin.
  2. Download the Example Project. Open it in the Unreal Engine Editor.
  3. Make sure that LadyBug Tracker is enabled. To do this, open the Plugins tab (Edit -> Plugins). Select the Bug Tracker category. For LadyBug Tracker, select the Enabled check box.
  4. Open the LadyBug Tracker tool window (Window -> Developer Tools -> LadyBug Tracker).

Setup project

  1. To open the plugin settings, click on the LadyBug Tracker toolbar.
  2. Enter the Host. To test the plugin, you can use my server http://104.238.158.97/mantisbt. Then click “Test” to make sure that the address is correct.
  1. To open the login window, click “Change login settings”.
  1. Enter the login and the password. If you use my server, enter “test” and “test”. Then click the “Login” button.
  1. Select an available project in the combo box.
  1. Close the settings, then return to the LadyBug Tracker window.

Issue list

  1. The Issues List tab shows all the issues from the database. If it does not show them, click to download all the issues again.
  1. Enter a phrase in “Filter Issues”. The list then shows all the bugs that contain this phrase in the Summary, Description or Additional Information field. For example, try “green”.
  2. Now try a more complex filter, for example “status = new category = gameplay”.

View Issue Detail

  1. Select an issue in the list. The Details tab shows the details of the selected issue.
  1. To open the issue in a web browser, click the link at the top of this panel.
  2. Scroll down to the Attachments section. To open an attachment in a web browser, click its link.
  1. To add a note to the issue, enter some text in the “Notes” section. Then click Add Note.

Edit Issue

  1. To start the edit mode, click in the “Details” tab.
  1. Change some properties, for example the category.
  2. To submit your changes, click .
  1. To assign the issue quickly, open the combo box and select a user.
  2. To change the status of the issue quickly, open the combo box and select a status.

Markers

  1. On the Issues List, the issues with 3D marker information have a tick in the column with the symbol. Select one of these issues.
  2. To open the level at the location that the issue specifies, click .
  3. To show all the bugs on the map, select .
  1. To open the issue of a ladybug marker in the Details tab, select the marker in the level viewport.
  2. To go to the location of a bug, double-click its ladybug marker.

Reporting Issue

  1. To make an issue, click .
  2. The new issue appears on the Pending List tab.
  1. Complete the details of the issue. To submit the issue, click .
  2. To make an editor issue entry, click .
  3. Scroll down to the Attachments section.
  4. Click the Edit button next to a screenshot. Select your favorite image editor, for example Paint (c:\windows\system32\mspaint.exe).
  1. Draw something. Then save your work and close the tool.
  2. Click . The plugin submits the issue and all its attachments to the server.
  3. To report a bug in the game, start the game in any mode. Then open the console and enter the “ReportBug some_bug_summary” command.
  4. If your game crashes, the plugin automatically makes an issue on the Pending List. This issue contains all the information that Unreal Engine dumped.

Reporting Automations

  1. Open the LadyBug Tracker settings. For each issue type, set the default values of the issue category, priority, severity and reproducibility. The plugin now applies these settings to new issues. Test it.
  2. You can make complex rules for the default values of new issues. Open MyIssueConstructor (Content/Blueprints/MyIssueConstructor.uasset) and add nodes that set a platform.
  1. In the settings, set Constructor Class to MyIssueConstructor.
  1. To test it, make an issue in the game.
  2. You can also configure the plugin to make issues automatically when specified conditions occur in the game. For example, the game can make an issue when a player falls under the terrain. Open ExamplePlayerController and look at the example implementation. To make the example simple, the game reports this bug when you press [R] in the game. Test it.
