Authentication

To log in from the plugin, you must first make a token. To make a token, do these steps:

  1. Open your user profile.
  2. Open the Account Security tab.
  3. Click New token....
  4. Enter any name, then click Create.
  5. In the login window, use your user name and the token to log in.

Project setup

  1. Open the Projects tab.
  2. Make a new project, or select a project that you already have.
  3. Open the Fields section.
  4. Add the Camera and Level fields.

Downloading only part of the project

By default, the plugin downloads all the issues in the project. To download fewer issues, use Project Settings > Plugins > LadyBug Tracker > YouTrack Settings > Issue Query Filter. The plugin adds the text of this setting to the project:{ProjectName} query that it sends. Write the filter in the YouTrack search syntax.

These are some frequent filters:

FilterWhat the plugin downloads
#UnresolvedOnly open issues
Type: BugBugs, but not features or tasks
Assignee: meIssues that are assigned to you
created: {This week}Issues that were reported this week

To download all the issues, keep the field empty. The plugin applies the filter when it downloads the issues. Thus, after you change the filter, download the issues again to see the result.

Subtasks

If the project has a subtask link type, an issue has a Subtask of field. This field shows a list of the issues that can be its parent. To put the bug under one of these issues, select that issue. To keep the bug independent, keep No parent in the field. You can change the field later. The issue then moves under the new parent.

The plugin shows the field only when the YouTrack project has a subtask link type. In a project without this link type, you cannot put a bug under a parent. Thus the plugin does not show the field.
