Asana

Asana is a work management service. It divides work into workspaces, and each workspace into projects of tasks. You can divide a project into sections. A task can have custom fields, subtasks, comments and attachments. LadyBug Tracker reports bugs as tasks in one Asana project.

Asana is free for up to 10 users.

Authentication

Asana uses personal access tokens. In the login window, enter this value:

  • Token — a personal access token from your Asana account.

To get a token, open My Settings > Apps > Developer apps in Asana (https://app.asana.com/0/my-apps), then make a personal access token. Asana shows the token only one time. Copy it immediately into the Token field. In the login window, the Create Token button opens this page.

The login window does not ask for a user name, because the token alone identifies the account.

The host address is always the Asana service. You do not need to change it.

Project setup (Asana service)

The plugin uses one Asana project in one workspace. The project settings have these two items:

  • Workspace selects the Asana workspace.
  • Project selects the project that gets the bug reports. The list does not show archived projects.

You can use a project that you already have, or the plugin can make a project for you. A project that the plugin makes has the sections that a game team usually needs:

  • General
  • Gameplay
  • Art
  • Sound
  • Level Design
  • UI
  • Other

Where the position is stored

Each bug that you report keeps the level and the camera from which you reported it. Asana has no field for these values. Thus the plugin writes them into the task description, and reads them from there. The values are part of the description. If you edit the description manually in Asana, you can lose them. Remember this before you write a new description in the web interface.

Integration capabilities

  • You can add, view and delete attachments.
  • You can add, view and delete comments.
  • Subtasks appear as a checklist that you can edit. Asana gives a task one list of subtasks. Thus a bug has only one checklist.
  • The plugin reads the custom fields that the project already has, and shows them with the issue.

Known limitations

  • Issue history is not available. The Asana API does not give the change log in the form that the plugin needs. Thus the History tab stays empty.
  • Status transitions are not available. A task is completed or not completed. The plugin sets this state directly. It does not move the task through a workflow.
  • The free plan has a limit of 10 users. Asana sets the limits for projects and storage.

Project setup (Unreal Engine)

Open Project Settings > Plugins > LadyBug Tracker. Then do these steps:

  1. Provider — select Asana.
  2. Change Login Settings — paste your personal access token.
  3. Workspace — select your Asana workspace.
  4. Project — select the project that gets the bug reports.

The plugin keeps these settings in Config/DefaultBugTracker.ini. You can share them with the team. The plugin keeps your token separately for each user. It keeps the token only when Remember Me is enabled.
