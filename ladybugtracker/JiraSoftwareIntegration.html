Jira Software Integration

Jira Software is a powerful platform. It combines issue collection and agile project management in one application. Jira Software helps you plan and organize tasks, workflows and reports for your agile team more efficiently.

Authentication

  1. In the plugin, open the login window. Then click Create Token.
  2. Your Jira account page opens. Click Create API token.
  3. Enter a name for the token, then click Create.
  4. Copy the token to the clipboard.
  5. Enter your login, then paste the token from the clipboard. Click Login.

Setup project

The easiest method to set up a project is to use the Bug tracking template.

  1. Click Projects, then click Create project.
  2. Select the Software development category.
  3. Select the Bug tracking template.
  4. Enter a project name and a key, then click Create project.
  5. Add two custom fields to the project, with the names Camera and Level. Both fields must have the type Short text. In Jira, it is not easy to add new custom fields. To learn how, read the Jira documentation. You must add these fields to use all the features of the plugin. https://confluence.atlassian.com/adminjiraserver/adding-custom-fields-1047552713.html
